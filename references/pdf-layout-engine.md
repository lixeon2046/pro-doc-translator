# PDF 版式回填引擎规范（TextWriter）

原理：逐页对文本块做脱字 redaction（保留图像/线条/表格边框/图形），再按原块几何回填译文。已验证实现：`scripts/engine_tw.py`（构建）、`scripts/patch_columns.py`（列拆分）、`scripts/extract_pdf.py`（提取）。

## 四条最高优先级规则（真实事故换来的）

### R1 · 绘制统一走 TextWriter
PyMuPDF 内置中文字体 `Font("china-s").text_length()` 与 `insert_text` 实际渲染宽度差 **1.39 倍**。折行/居中用度量、绘制用 insert_text，必然系统性越界（实测一行溢出 100+pt）。TextWriter 的 `append` 与度量 1:1 一致（实测比值 1.000）。旋转文本用 `write_text(morph=(point, Matrix(90|270)))`。伪粗体 = 同位偏移 0.28pt 双绘。

### R2 · 表格列合并块必须拆分
PyMuPDF 常把同一行相邻列的单元格文字合并为一个 block：多"行" y 相同（±2.5pt）、x 分离（间隙 >2pt）。若不拆，按上下行绘制会叠印/跨栏。拆分算法（`patch_columns.py`）：
1. 行聚类（y 容差 2.5pt）→ 任一行内存在 x 间隙 >2pt 的分段 → 判定列合并
2. 每个源行生成单行伪块（继承字号/颜色/旋转，id=`父id#行号`）
3. 译文按源行号从父块译文逐行分配；⚠️ 伪块中的 `⟦N⟧` 占位符必须按**父块全文数字序列**解析（行内解析必然错位）

### R3 · 占位符作用域 = 解析基准
`⟦N⟧` 数字占位符的索引绑定生成它的那份文本（通常为整块）。任何变换（拆分、合并、行绘制）后解析时，数字序列必须取自同一份基准。曾因跨文档共享缓存导致页脚页码丢失、表格数值整体错乱。构建时任何 `⟦N\d` 未解析 → 该块按约定回退（黄高亮或 `__DROP__`）。

### R4 · 行级锚定用每行自身 x0
块内不同列/不同缩进的行各有起点。译文行数=源行数时逐行落位：y=源行 y，x=源行 x0（align=c 用源行中心）。译文行较少时：表格行组在"行 x0 众数"起排全高均布（⚠️ 同时按收窄后的宽度重折行，否则右溢）；段落自然折行顶部对齐。

## 布局细则

| 场景 | 处理 |
|---|---|
| 单行源块中文略长 | 缩字号排一行，下限 4.7pt；宽块（>300pt）下限 0.78×字号，仍放不下→向下借 9pt 走两行 |
| 窄表格单元格块 | bbox 扩展到所在单元格全宽（仅 nlines==1 且完全在格内；跨栏块禁止） |
| 目录条目 | 标题 + 点线 + 右对齐页码重建（点线数量按度量计算） |
| 页码类重复文本 | 规范译文表中用 `⟦N⟧` 占位，构建时按各页实际数字回填 |
| 纯数字/符号块 | 原样绘制（无需译文） |
| 不再需要的内容 | 译文填 `__DROP__`：只脱字不回填 |
| 旋转表头/标签 | rot=90 自下而上 / 270 自上而下，逐行推进 |

## 封面免责声明（默认开启，用户可豁免）

参考译本声明框绘制于封面空白区（圆角边框+浅底），参数化：`engine_tw.add_disclaimer(pdf, text=..., rect=...)`。文本由用户提供或使用默认模板。

## 书签中文化

两级映射：① 目录页译文（英文条目→中文条目）；② 正文标题块按编号前缀映射（x.y.z 级）。仅接受含中文的候选，避免被历史修订表条目覆盖；`€` 等 artifact 清洗。

## 已知误报（QA 裁决时排除）

- 伪粗体双绘 → 提取为两个同文 span（叠印检测按同文豁免）
- 行框上下伸部相触（高 1–2pt 交集）
- `。`（U+3002）不在 `\u4e00-\u9fff` 内 → 微字检测须含 CJK 标点段
- 表格线距文字 ±数像素 → 视觉验收以"可读性"为准
