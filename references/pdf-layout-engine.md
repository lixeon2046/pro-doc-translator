# PDF 版式回填引擎规范（TextWriter）v2

原理：逐页对文本块做脱字 redaction（保留图像/线条/表格边框/图形），再按原块几何回填译文。已验证实现：`scripts/engine_tw.py`（构建）、`scripts/build_doc.py`（构建驱动 + BUILD_FIX）、`scripts/patch_columns.py`（列拆分）、`scripts/extract_pdf.py`（提取）、`scripts/preflight_pdf.py`（健康预检）。

## 最高优先级规则（真实事故换来的）

### R1 · 绘制统一走 TextWriter
PyMuPDF 内置中文字体 `Font("china-s").text_length()` 与 `insert_text` 实际渲染宽度差 **1.39 倍**。折行/居中用度量、绘制用 insert_text，必然系统性越界。TextWriter 的 `append` 与度量 1:1 一致。注意：`TextWriter.append()` **不接受 color 参数**——页内混色需按颜色分组多个 TextWriter，各自 `write_text(color=)`（`Pen` 类已实现）。旋转文本用 `write_text(morph=(point, Matrix(90|270)))`。伪粗体 = 同位偏移 0.28pt 双绘。

### R2 · 表格列合并块必须拆分
PyMuPDF 常把同一行相邻列的单元格文字合并为一个 block：多"行" y 相同（±2.5pt）、x 分离（间隙 >2pt）。若不拆，按上下行绘制会叠印/跨栏。拆分算法（`patch_columns.py`）：
1. 行聚类（y 容差 2.5pt）→ 任一行内存在 x 间隙 >2pt 的分段 → 判定列合并
2. 每个源行生成单行伪块（继承字号/颜色/旋转，id=`父id#行号`）
3. 译文按源行号从父块译文逐行分配；⚠️ 伪块中的 `⟦N⟧` 占位符必须按**父块全文数字序列**解析（行内解析必然错位）
4. 伪块译文写入 `trans/<doc>_cZZ.json`（⚠️ `_cNN` 是真实分块号，勿用纯数字后缀与真实块撞名）

### R3 · 占位符作用域 = 解析基准
`⟦N⟧` 数字占位符的索引绑定生成它的那份文本。任何变换（拆分、行重排、合并）后解析时，数字序列必须取自同一份基准。构建期任何 `⟦N\d` 未解析 → 该块回退（黄高亮或 `__DROP__`）。**行序重排与占位符重映射必须且只能在一个地方应用一次**（`build_doc.py` 的 `fix_zh`）——文件级和构建级同时应用会互相抵消，这是幂等性事故。

### R4 · 行级锚定用每行自身 x0
块内不同列/不同缩进的行各有起点。译文行数=源行数时逐行落位：y=源行 y，x=源行 x0（align=c 用源行中心）。译文行较少时：表格行组在"行 x0 众数"起排全高均布（同时按收窄后的宽度重折行，否则右溢）；段落自然折行顶部对齐。

### R5 · 同行多列碎片的行高守卫
分数上下片、双列单元格等同行碎片：相邻"行"的 y 差 <0.9×字号时，row_h 必须取该行自身 line_hs，**不得**用 `(相邻行距−fs)/2` 推算——否则碎片被垂直抬升成假上标（实测把 `2t` 排成 `2^t`，歪曲公式含义）。

### R6 · 旋转 90° 表格（竖排表格页）的三层锚定规则
ASME/工程手册常见"横排表格旋转 90° 印在竖版页"。旋转块的行几何语义与横排**完全不同**，用横排行模型解释必然叠印（div.3 第 98–124 页 KM-400 材料表实测）：
- **字段语义**：`line_ys[i]` = 第 i 行文字沿书写方向的**起点**；`line_hs[i]` = 该行**文字长度**（不是厚度！）；条带（字形厚度方向）位置在 `line_x0s[i]`，宽度 = 块缘 − x0s[i]。
- **逐行锚定 + 跨度内居中**：短标签（表头词组）在源行跨度 `[line_ys, line_ys+line_hs]` 内**居中**——源表头组是居中排版，中文更短时按源起点底锚会产生阶梯漂移。
- **跨度判据**：译文长度 ≥ 72% 源行跨度时（通栏表题、整段注释）保持**端部锚定**——无条件居中会把整页高的表题画到页面中部压住表格（实测事故）。
- **行数必须 1:1**：旋转表格块禁止合并短行（"Spec. No." 与 "…" 各占一行就是两行）。行数不等（译文 7 行 vs 源 13 行）时逐行映射失效、退化为堆叠模式，多行压进 8pt 条带形成叠印团。翻译任务书须明示此红线；行数失配的存量译文按源行逐行字典化再生（Wire→钢丝、Oil→油淬、板材/螺栓…，数值/牌号/…原样）。
- **溢出对称**：厚度范围行（"100 < t ≤ 180"）文字长于行高时，锚定取跨度**中点**使溢出对称分布到两侧空带，而非单端压向相邻数据行。
- 上述全部实现于 `engine_tw.insert_rot`（逐行模式 + 堆叠模式自动分派）。

### R7 · 撇号/上标类字形映射错误只能靠像素发现
图内引线标注 `A5i′s` 被提取为 `A5i9s`、`F′` 提取为 `F9`（PDF ToUnicode 映射错误，提取层与预检层都无法察觉）。**预防**：公式页/插图页属截图对比**必抽页**（qa-protocol §三）；图内符号标注保留原样时，与源图并排逐个核对字形。发现一处即排查同页同类（本项目 A5i′s 修复后同图 F′ 漏网，被复验抓出）。

## 四类源 PDF 陷阱（preflight_pdf.py 自动检测）

| 陷阱 | 症状 | 修复 |
|---|---|---|
| **连字/编码置换** | 提取文本出现 `ð25Þ`(=(25))、`Ɵ`(=ti)、`ﬁ`(=fi)；非 ASCII 字符审计发现成对等量的 `ð/Þ` | 提取后归一化映射表（`ð→( Þ→) Ɵ→ti ﬁ→fi ﬂ→fl ﬀ→ff 软连字符→删除`）；先全文档扫描字符分布再定表 |
| **内容流悬挂 CTM** | TextWriter 绘制的文本整体位移（Shape 画的矩形不受影响，因为自包裹 q/Q） | 逐页 `page.clean_contents()` 平衡内容流 |
| **MediaBox ≠ CropBox** | TextWriter 按 MediaBox 解释坐标、渲染按 CropBox → 系统性偏移（如 612×792 裁成 612×612 差 180pt） | Pen 内加 `(mediabox.x0−cropbox.x0, mediabox.y1−cropbox.y1)` 偏移（已内建） |
| **Logo 字体徽标** | 徽标/椭圆是内嵌 Logo 字体的**字形**而非矢量/图像；红框脱字（text remove）即永久丢失且不可重绘 | 该块整块保留不译（`drop_ids`）；混合块用 `line_splits` 只拆出可译行 |

## 探针实验协议（坐标类异常的唯一可信排查法）

静态分析（读变换矩阵、猜坐标系）两次都可能误判。凡绘制位置异常：
1. 在问题页画一个**红色标记矩形**（Shape/draw_rect，自包裹不受 CTM 影响）；
2. 用 TextWriter 在**已知坐标**写一段测试文本；
3. 渲染成 PNG，量取两者的实际落点，差值即变换偏移；
4. 修复后再以同法复验。
**文本提取是证据，渲染像素是真相**：字形丢失、层级错位类问题必须以渲染验证收尾，`get_text` 的结果会骗人（字体合并、行分组、层级）。

## 版式细则

| 场景 | 处理 |
|---|---|
| 单行源块中文略长 | 缩字号排一行，下限 4.7pt；宽块（>300pt）下限 0.78×字号；**窄表格单元格（<60pt）下限 4.2pt**（宁可微缩保单行，防折行穿表格线），仍放不下→向下借 9pt 走两行 |
| 窄表格单元格块 | bbox 扩展到所在单元格全宽（仅 nlines==1 且完全在格内；跨栏块禁止） |
| 目录条目 | 标题 + 点线 + 右对齐页码重建（点线数量按度量计算）；⚠️ 点线正则必须线性（`[.\s]{6,}`），回溯式正则在长点线上 CPU 爆转 |
| 页码类重复文本 | 规范译文表中用 `⟦N⟧` 占位，构建时按各页实际数字回填；组内各变体**数字段数必须一致**才可入表（护栏），否则交分块翻译 |
| 纯数字/符号块 | 原样绘制。`is_symbolic()`：无 ≥4 字母拉丁词、无 CJK、字符全在符号白名单（含希腊字母、√ÅÄÅÉÑ 等）；**同字符连排**（`jjjj`/`ÅÅÅÅ`）视为方程括线字形 |
| 方程碎块（ASME 类） | `ÄÇÅÉÖÑ/jjjj/zzzz/k/{` 是大括号/大括线的字体碎片——保持原样不译；`\x02-\x07` 控制字符为关系/希腊符号（`≥ = σ θ α`），**按图题语境逐图判定**（不同图字体映射不同，Part4 图 \x02=≥ 而 Part5 图 \x02==），不可辨识则原样保留 |
| 旋转表头/标签 | rot=90 自下而上 / 270 自上而下，逐行推进 |
| 不再需要的内容 | 译文填 `__DROP__`：只脱字不回填（跨图断句吸收、冗余碎片、水印） |

## BUILD_FIX 声明式修复清单（`.work/build_fix.json`）

视觉验收的每个 fail → 一条精确修复记录；**禁止大面积启发式改动**。驱动：`scripts/build_doc.py`。字段：

```json
{
  "文档键": {
    "display_name": "ASME Section VIII - div.1",       // 输出文件名用（历史键映射现名）
    "source_pdf":   "ASME Section VIII - div.1.pdf",   // 可选，源 PDF 现名
    "drop_ids":      ["p1b8"],                          // 整块保留原样（Logo 字形块）
    "drop_prefixes": ["www.bzfxw.com", "标准分享网"],     // 水印：只脱字不回填
    "line_splits": { "p1b2": [                          // 混合块拆行（封面标题分层等）
        {"line": 0, "new_id": "p1b2a", "size": 22},
        {"line": 1, "new_id": "p1b2b", "size": 14, "dy": -10},
        {"line": 2, "new_id": "p1b2c", "size": 30, "color": 16777215} ] },
    "trans_overrides": { "pNNbM": "定点译文",           // 含伪块 id
                         "pNNbK#0": "__DROP__",        // 只脱字
                         "pNNbJ": {"append": "并句"} }, // 跨图断句并入前块
    "lys_shift": { "p1b0": [0, -10] }                   // 整块行 y 偏移
  }
}
```

## 免责/版权声明（默认**亮黄醒目**样式）

`engine_tw.add_disclaimer(pdf, text=..., rect=..., style="yellow")`：亮黄底 + 深红边框/标题（用户指定的醒目风格，默认）；`style="plain"` 为米色低调样式（封面留白紧张时）。放置前必须检查封面块布局（提取 JSON 首页 bbox），确认矩形落在空白区、末行基线 < 框底、不与原元素冲突。

## 已知误报（QA 裁决时排除）

- 伪粗体双绘 → 提取为两个同文 span（叠印检测按同文豁免）
- 行框上下伸部相触（高 1–2pt 交集）
- `。`（U+3002）不在 `\u4e00-\u9fff` 内 → 微字检测须含 CJK 标点段
- 表格线距文字 ±数像素 → 视觉验收以"可读性"为准
- 越界/微字先对**源文件跑基线**：源版式本身越界的页眉/修订标记（如 ASME "(25)" 在 x581）不算新增缺陷，只追基线外的新增项
