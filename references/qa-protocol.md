# QA 协议与视觉验收闭环 v2

三层：**译文 QA**（翻译流水线出口）、**成品 QA**（PDF/Office 出口）、**截图对比验收**（像素级终审）。全部归零才交付。

## 〇、基线对照法（成品 QA 的前提）

越界/微字/叠印扫描**先对源文件跑一遍建立基线**，只追"新增"项：
- 源版式本身越界的页眉/修订标记（如 ASME 页脚代码在 x581、"(25)" 角标越栏）不是缺陷；
- 源版本身的 4.3pt 小字是忠实还原对象；
- 判定规则：成品命中项中，同页 ±10pt 内源文件也命中的 → 忠实豁免；否则为新增缺陷需逐条裁决。
`qa_scan.py --src src.pdf` 已支持对照；无 --src 时输出全量需人工过滤。

## 一、译文 QA（每分块出口 + 全量合并后）

`scripts/validate_trans.py <workdir>` 六项检查：
- id 一一对应（missing/extra 必须为空）
- JSON 合法；null 仅限乱码条目
- `⟦⟧` 占位符与源一一对应（R3）
- **字面转义污染**（译文含字面 `\n` `\t`——会原样印入成品，实测曾 118 条污染 6+ 页正文）
- **截断嫌疑**（译文 < 源文 12% 且源文含拉丁词；WARN 级，须对照源文逐条裁决——实测抓出 50 条"只译标题丢正文"，其中约半数伴随跨块链式漂移，修复时需连带再平衡相邻块键）
- null 统计

术语漂移扫描（glossary_drift 逻辑）：
- 统一术语的禁用变体表 + 英文术语残留检测
- ⚠️ 命中项必须对照英文原文逐条裁决后才修改——扫描器有系统性误报类：
  - 合法词包含禁用子串（如"验船师"含"验船"）
  - 源文本本就不同的概念（test load 试验载荷 ≠ proof load 验证载荷）
  - 实体标记按约定保留英文

## 二、成品 QA（PDF 出口）

`scripts/qa_scan.py <out.pdf> [--src src.pdf]`：
- 文字越界右缘（x > 版心+容差；基线对照豁免源版固有项）
- `⟦⟧` 占位符残留（必须为 0）
- 微字：CJK（含标点 `\u3000-\u303f`）字号 < 4.5pt（基线对照；窄表格单元格引擎下限 4.2pt 为可接受设计）
- 页脚页码：逐页核对"第 N 页"连续（原版无页脚的页按约定豁免）
- 叠印：不同文本 span 相交（伪粗体同文双绘豁免；行框相触 h<2pt 豁免）

`scripts/tables_coverage.py <src.pdf> <out.pdf>`：
- 源表格含源语言文字的单元格，输出同位置（±7pt）必须检出目标语言
- 缺失率 ≤5% 可接受（剩余通常为按约定保留的标准代号/位图插图内文字，需逐条裁决确认）

残留源语言扫描：白名单 = 内部标记、机构地址、标准号/牌号、公式、约定保留的实体标记、图内轴标（图形艺术层）。

## 三、截图对比验收（复杂公式与大型表格**必抽**）

QA 扫描通过 ≠ 版式可读。`scripts/visual_diff.py` 生成验收证据：

```bash
# 自动挑复杂版式页（矢量图元+图片+短行密度加权）+ 指定公式/大表页 + 关键区域放大
python visual_diff.py src.pdf out.pdf --auto 4 --pages 722 497 \
    --crop 722:100,255,520,345 --tag mydoc
# → .work/visual_diff/mydoc/pNNN_pair.png（左源右成品并排）+ pNNN_crop_N.png（200dpi 放大）
```

**必抽页类型**：公式密集页（方程碎块/分式/上下标）、列数 ≥6 的大表、跨页表、矩阵/旋转表头、表单类、封面。并排图交视觉验收代理裁决。

**裁决标准**（对照源逐处核对）：
- 无乱码/叠印不可读/裁切丢字；文字在栏框内、竖线不穿字
- 表格行对齐 ±数像素可接受；字号 ≥4.5pt 可辨（窄格微缩例外需放大可读）
- **数值/公式/编号/单位与源逐格一致**（每页至少抽 3 处）
- 公式结构不失真：分式上下片基线正确、关系符（=/≥）无篡改、变量名完整
- 免责/版权声明框完整、文字不溢出、页脚连续

**像素真相原则**：`get_text` 提取会骗人（字体合并字形、同位叠字、层级分组）。凡"看着不对"或"提取正常但存疑"的位置，一律渲染放大到 200dpi 看像素；字形丢失类缺陷（Logo、上标 S、分母）只有渲染能发现。

## 四、修复闭环

1. 视觉 fail → **精确定位缺陷块**（提取输出 PDF 对应位置 span 的 size/bbox 反查；必要时 rawdict 逐字符坐标）
2. 修复落成 **BUILD_FIX 声明式记录**（`.work/build_fix.json`：drop_ids / line_splits(size,color,dy) / trans_overrides / lys_shift / drop_prefixes）——禁止大面积启发式改动（曾因通用合并策略把正确单元格内容并错栏位）
3. 重建 → **复验原 fail 页**（防修复引入回归：修复徽标保留时曾连带删相邻块文本，需全量重建自愈）
4. 全部 pass → 垃圾回收（garbage=4）+ 完整性校验 + 交付

## 五、构建摘要报告（交付附件）

每份文档一行：页数 | 译文条目 | QA 各项计数（含基线对照后新增值）| 截图对比页清单 | 视觉验收结果 | BUILD_FIX 修复记录 | 输出路径。
