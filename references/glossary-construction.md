# 领域词汇表自动构建协议

没有现成词汇表时的标准作业程序。目标：产出三层结构的 `glossary.md`，使任何子代理都能做出与领域专家一致的术语决策。

## 1. 领域判定

- 采样：封面、目录、每章首段、高频大写词、图表标题
- 判定主领域 + 子领域 + 相邻领域（如"海洋工程 → 吊装/焊接/材料"）
- 多领域混合文档按章节登记各自领域
- 输出一句话领域声明，供后续 WebSearch 与译者使用

## 2. 术语挖掘（候选生成）

| 来源 | 方法 |
|---|---|
| 缩写 | regex `\b[A-Z]{2,}[0-9]*\b` 过滤常见英文词；记录全文档首现位置 |
| 多词术语 | 2–4 gram 频率统计，剔除停用词组合；表格表头/图注加权 |
| 定义句式 | "X means / X refers to / X shall mean / X是指/所称的X" |
| 既有双语线索 | 源文档内括号注音、参考文献中的双语标准名 |
| 高频专名 | 组织名、产品名、地名（多进入 keep-original 层） |

每个候选记录：出现次数、出现分块、上下文样例 1 条。

## 3. 权威查证（WebSearch）

按优先级检索官方译法：
1. 标准组织/行业机构官方双语文件（ISO/IEC/IEEE/EN/GB/行标/行业权威团体……的中文版或术语页）
2. 全国科学技术名词审定委员会（term.org.cn）审定名词
3. 该领域头部企业的官方中文文档/手册
4. 权威百科与学术数据库的通用译法（多来源交叉验证）
5. 都没有 → 标记 `translator-decided`，由资深译者按构词法+领域惯例决策

每条记录：`英文 | 中文 | 来源URL/说明 | 置信层`。

## 4. 分层定稿（glossary.md 结构）

```markdown
## verified（有权威来源，强制）
| 英文 | 中文 | 来源 |
## consistent（自洽决策，全文强制统一）
| 英文 | 中文 | 决策理由 |
## keep-original（保留原文）
标准号、牌号、单位、代码、品牌、型号、公式符号
## 语气与文体规范
shall=应 shall not=不应 should=宜 may=可 must=必须
数字/单位/标点全半角规则；中英文间空格规则
```

## 5. 翻译期动态维护

- `terms.log`：子代理每块追加 ≤5 条新决策（`中文=English`），后续块强制延续
- 主控在块间抽查 terms.log，发现冲突立即裁决并回改
- 全文完成后将 terms.log 高频条目回灌 glossary.md（资产沉淀，下次项目复用）

## 6. 快速通道

- 用户提供现成词汇表 → 合并为 verified 层，跳过查证
- 同领域二次项目 → 直接复用上次 glossary.md（资产沉淀的意义）
